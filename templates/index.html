6. About Project

Educational context, design philosophy, and data structures utilized.

CPU Scheduling Lab was developed as a college Data Structures and Algorithms (DSA) project. The platform bridges theoretical operating system concepts with hands-on computer science data structures.

Binary Min-Heap Implementation

Implemented manually from scratch in Python (without heapq). Processes are maintained in a complete binary tree backed by an array. The scheduler extracts the root in O(log N) time for Priority, SJF, and SRTF scheduling.

FIFO Queue Implementation

Implemented manually to model the strict First-In, First-Out queueing discipline required for Round Robin time-slicing and FCFS. Processes are enqueued at the tail and dequeued from the head in O(1) time.
